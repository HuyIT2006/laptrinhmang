Xóa thư mục $WINDOWS.~LS (Giao động từ 10GB - 20GB)Thư mục này xuất hiện ngay ở gốc ổ C trong tấm hình đầu tiên bạn gửi, đây là bộ cài đặt nâng cấp Windows cũ còn sót lại.Nhấn Windows + S $\rightarrow$ gõ Disk Cleanup $\rightarrow$ chuột phải chọn Run as administrator.Chọn ổ C: $\rightarrow$ tích chọn Previous Windows installation(s) và Temporary Internet Files $\rightarrow$ bấm OK để xóa.2. Tắt Hibernate (Giải phóng ngay 8GB - 16GB)Windows mặc định tạo một file ẩn tên hiberfil.sys ở ổ C để lưu trạng thái ngủ đông, dung lượng file này bằng đúng dung lượng RAM máy bạn.Mở Command Prompt hoặc PowerShell bằng quyền Administrator.Gõ lệnh powercfg -h off rồi nhấn Enter. Ổ C sẽ tăng dung lượng trống ngay lập tức.
